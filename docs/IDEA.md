# Todo 앱 아이디어

## 한 문장 정의
혼자 쓰는 간단한 할 일 목록 웹 앱

## MVP (꼭 필요한 것)
- 할 일 추가 (제목 필수, 1~100자)
- 할 일 목록 보기 (만든 시간 기준 최신순)
- 완료/미완료 전환 (체크박스)
- 할 일 삭제
- 새로고침해도 데이터 유지 (v0.3에서 완성)

## 세부 규칙
### 입력 검증
- 제목의 앞뒤 공백은 잘라낸다
- 공백만 있는 제목은 추가하지 않는다
- 100자를 넘으면 에러 메시지를 표시한다
- 같은 제목의 중복은 허용한다

### 정렬
- 만든 시간 기준 최신순
- 완료해도 목록에서의 자리는 그대로 유지한다

### 삭제
- 확인 창 없이 바로 삭제한다

### 화면 상태
- 빈 목록일 때: "할 일이 없습니다"
- 서버 요청 실패 시: 에러 메시지를 표시한다

## 지금은 빼는 것

## 기술 스택
- Next.js (App Router) + TypeScript + Tailwind
- DB: Postgres (Neon) + Drizzle
- 배포: Vercel
- 세부 사항은 CLAUDE.md에서 정한다

## 주의사항
